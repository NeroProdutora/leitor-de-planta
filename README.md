# Leitor de Planta

A planta baixa do seu projeto vira uma página animada: o cliente passa o mouse num ambiente, ele se enche de cor e o nome aparece. No celular, é só tocar.

## O que você precisa

- Claude Code instalado, num Mac.
- A planta de cada pavimento em PDF, PNG ou JPG. Planta humanizada ou só de traço, as duas servem. O melhor caso é o PDF exportado do programa de desenho, que costuma trazer o nome e a área de cada ambiente como texto.

## Como usar

1. Nesta página do GitHub, clique em **Code** e depois em **Download ZIP**. Abra o arquivo baixado: ele vira uma pasta.
2. Abra essa pasta no Claude Code.
3. Arraste a planta para a pasta `planta/`.
4. Escreva: **"lê a minha planta e deixa ela animada"**.

O Claude lê a planta, separa os ambientes, mostra a leitura para você conferir os nomes e monta a página em `saida/`. Na primeira vez ele instala as ferramentas, o que leva alguns minutos.

## Depois

- As cores você escolhe num painel ao lado da planta: paletas prontas, tom mais quente ou mais frio, mais suave ou mais viva, e a cor de cada ambiente.
- Quer mudar um nome ou um recorte? Peça com as suas palavras.
- A pasta em `saida/` é o site completo. Abre direto no navegador e pode ser publicada em qualquer hospedagem de site estático.
- Sua planta fica guardada no seu computador. Para ler, o Claude recebe a imagem dela, como acontece com qualquer arquivo que ele abre. Nada é publicado sem você pedir.
